# Architecture decision: Electron desktop
Proposed implementation: Electron 45, JavaScript ES modules, local HTML/CSS renderer; ssh2 for SFTP, basic-ftp for FTP/explicit FTPS. No frontend framework/build chain required for this first version. Main process owns filesystem, credentials and network; preload exposes narrow operations, renderer only presents state. Electron safeStorage protects remembered secrets with OS-backed encryption. Protocol adapters expose the same filesystem operations; queue is transport-agnostic. UI/core/adapters separated for later Windows packaging.
Current host Node 20 is below Electron installer requirements; use a project-local Node 22 runtime, no system-wide install. Dependencies pinned with lockfile. Release signing/notarization and external distribution are out of this local development milestone.
References: https://www.electronjs.org/docs/latest/tutorial/security ; https://github.com/mscdex/ssh2 ; https://github.com/patrickjuchli/basic-ftp
